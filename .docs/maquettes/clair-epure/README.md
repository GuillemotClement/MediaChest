La page d’erreur illustre une page introuvable (404). L’état is-error illustre un échec de récupération des données dans la page. L’état liste-vide illustre une liste personnelle sans média.

Les versions mobiles sont des maquettes à haute densité conçues pour un viewport d’environ 390 pixels CSS ; les dimensions raster ne sont pas les dimensions CSS à reproduire.

Les affiches et informations illustrent le design et ne constituent pas des données TMDB vérifiées. Les visuels générés peuvent présenter de légères variations de typographie et d’espacement entre écrans.

Les prompts exacts sont conservés dans [prompts.md](prompts.md).
